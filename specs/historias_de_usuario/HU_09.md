### 📋 HU-09: Arquitectura de Carrito de Compras Persistente (Validación en Tiempo Real)

**Como** Cliente autenticado de SneakerHub Ayacucho  
**Quiero** validar la disponibilidad y precio de los artículos de mi lista de selección temporal antes de consolidarlos en el carrito  
**Para** garantizar que los productos seleccionados cuenten con existencias físicas reales en el almacén de MySQL antes de proceder al checkout.

---

#### 📌 1. Precondiciones y Postcondiciones
* **Precondiciones:**
  1. El usuario debe estar autenticado con un token JWT vigente bajo el guardián elástico `verificar_usuario`.
  2. El cliente frontend (React) administra la persistencia local de los ítems seleccionados (mediante `localStorage`).
* **Postcondiciones:**
  1. El backend emite un dictamen de consistencia de stock, confirmando o rechazando la viabilidad de cada artículo.
  2. El frontend actualiza los estados de la interfaz de usuario, bloqueando o autorizando el avance hacia la pasarela de pagos.

---

#### 🛠️ 2. Criterios de Aceptación Técnicos Detallados
* **CA-01 (Seguridad Perimetral del Cliente):** El endpoint de validación del carrito requiere obligatoriamente la cabecera `Authorization: Bearer <JWT>`. Peticiones anónimas son rechazadas inmediatamente con un código **401 Unauthorized** por el guardián de sesión.
* **CA-02 (Verificación de Stock en Tiempo Real):** Por cada elemento enviado en la lista del carrito, el backend cruzará el `producto_id` y la `talla` contra la matriz de almacenamiento físico (`TallaStock`). Si la `cantidad` solicitada por el cliente supera el stock remanente disponible en la celda ($cantidad > stock$), el sistema marcará el ítem con estado de error, impidiendo sobreventas concurrentes.
* **CA-03 (Sincronización Dinámica de Precios comerciales):** Para evitar que un usuario altere los subtotales modificando el JSON local del navegador, el backend ignorará los precios enviados por el cliente. El controlador extraerá el `precio_base` y el `porcentaje_descuento` directamente de MySQL, calculando el precio neto real en el servidor.
* **CA-04 (Estructura de Respuesta Detallada):** El servidor responderá con un desglose completo que incluye un indicador booleano general de viabilidad (`disponible`), el precio calculado con descuento aplicado y un mensaje de alerta específico si el stock es insuficiente.

#### 📊 3. Esquemas de Validación y Contratos de Datos (Pydantic)

```python
from pydantic import BaseModel, Field
from typing import List, Optional

# Esquema de Entrada: Ítems enviados desde el localStorage del Frontend
class ItemCarritoInput(BaseModel):
    producto_id: int = Field(..., description="ID del producto a validar")
    talla: str = Field(..., description="Talla comercial seleccionada")
    cantidad: int = Field(..., ge=1, description="Cantidad de pares solicitados")

class ValidarCarritoPayload(BaseModel):
    items: List[ItemCarritoInput] = Field(..., description="Lista de artículos en el carrito temporal")

# Esquema de Salida: Dictamen técnico de validación
class ItemCarritoValidado(BaseModel):
    producto_id: int
    nombre: str
    talla: str
    cantidad_solicitada: int
    stock_disponible: int
    precio_unitario_neto: float
    viable: bool = Field(..., description="Indica si hay stock suficiente para procesar este ítem")
    mensaje_error: Optional[str] = None

class CarritoValidacionResponse(BaseModel):
    items_validados: List[ItemCarritoValidado]
    carrito_viable: bool = Field(..., description="True si absolutamente todos los ítems tienen stock")
    monto_total_estimado: float
```

#### 🗄️ 5. Implementación del Algoritmo del Controlador (FastAPI + SQLAlchemy)

```python
from fastapi import APIRouter, Depends, status
from sqlalchemy.orm import Session, joinedload
from app.database import get_db
from app.models.product import Producto
from app.models.variant import TallaStock, VarianteColor
from app.schemas.product import ValidarCarritoPayload, CarritoValidacionResponse, ItemCarritoValidado
from app.routers.auth import verificar_usuario

router = APIRouter(prefix="/api/productos", tags=["Productos"])

@router.post(
    "/carrito/validar", 
    response_model=CarritoValidacionResponse,
    status_code=status.HTTP_200_OK,
    summary="Validar consistencia de precios y stock del carrito de compras web"
)
def validar_consistencia_carrito(
    payload: ValidarCarritoPayload,
    db: Session = Depends(get_db),
    usuario_actual = Depends(verificar_usuario)
):
    items_validados = []
    carrito_viable = True
    monto_total_estimado = 0.0

    # 1. Iterar y auditar de forma síncrona cada ítem provisto por el cliente frontend
    for item in payload.items:
        # Extraer el producto con su árbol relacional de variantes indexadas
        producto = db.query(Producto).options(
            joinedload(Producto.variantes_color).joinedload(VarianteColor.tallares_stock)
        ).filter(Producto.id == item.producto_id, Producto.estado == "ACTIVO").first()

        if not producto:
            items_validados.append(
                ItemCarritoValidado(
                    producto_id=item.producto_id,
                    nombre="Producto No Disponible",
                    talla=item.talla,
                    cantidad_solicitada=item.cantidad,
                    stock_disponible=0,
                    precio_unitario_neto=0.0,
                    viable=False,
                    mensaje_error="El calzado solicitado fue descontinuado o no existe."
                )
            )
            carrito_viable = False
            continue

        # Locallizar la celda exacta de inventario para la talla solicitada
        stock_celda = 0
        for variante in producto.variantes_color:
            for ts in variante.tallares_stock:
                if ts.talla == item.talla:
                    stock_celda = ts.stock
                    break

        # 2. Calcular el precio neto en el servidor aplicando reglas promocionales (HU-12)
        descuento = producto.porcentaje_descuento if producto.porcentaje_descuento else 0.0
        precio_neto = producto.precio_base * (1 - (descuento / 100.0))

        # 3. Evaluar la suficiencia matemática del inventario físico remanente
        tiene_stock = stock_celda >= item.cantidad
        error_msg = None if tiene_stock else f"Stock insuficiente en almacén. Unidades disponibles: {stock_celda}"
        
        if not update_stock := tiene_stock:
            carrito_viable = False

        if tiene_stock:
            monto_total_estimado += precio_neto * item.cantidad

        items_validados.append(
            ItemCarritoValidado(
                producto_id=producto.id,
                nombre=producto.nombre,
                talla=item.talla,
                cantidad_solicitada=item.cantidad,
                stock_disponible=stock_celda,
                precio_unitario_neto=round(precio_neto, 2),
                viable=tiene_stock,
                mensaje_error=error_msg
            )
        )

    return CarritoValidacionResponse(
        items_validados=items_validados,
        carrito_viable=carrito_viable,
        monto_total_estimado=round(monto_total_estimado, 2)
    )
```

### 📋 HU-05: Módulo de Gestión de Galería Multimedia

**Como** Administrador de la plataforma SneakerHub Ayacucho  
**Quiero** registrar, listar y eliminar enlaces URL de imágenes vinculadas a una variante cromática específica de un producto  
**Para** alimentar la galería multimedia interactiva del frontend, permitiendo que los clientes aprecien el calzado desde múltiples ángulos según el color seleccionado.

---

#### 📌 1. Precondiciones y Postcondiciones
* **Precondiciones:**
  1. El usuario debe autenticarse con un token JWT vigente que poseva el rol jerárquico de **"admin"**.
  2. La fila correspondiente a la variante física (`variante_color_id`) ya debe estar previamente creada e indexada en la tabla `variantes_color`.
* **Postcondiciones:**
  1. Las URLs de los recursos estáticos se guardan en la tabla `imagenes` vinculadas mediante una clave foránea rígida hacia la variante de color.
  2. Al eliminar una imagen, el registro se borra físicamente (`HARD DELETE`) de MySQL, rompiendo el enlace de forma inmediata en la interfaz pública.

---

#### 🛠️ 2. Criterios de Aceptación Técnicos Detallados
* **CA-01 (Seguridad Perimetral de Datos):** Los endpoints mutadores (`POST`, `DELETE`) están bajo el estricto control de acceso del guardián `@verificar_admin`. Cualquier solicitud externa sin token válido o con rol "cliente" será expulsada con un código de respuesta **403 Forbidden**.
* **CA-02 (Validación de Existencia de Variante):** El backend debe ejecutar un control preventivo verificando la presencia real en la base de datos de la variante apuntada por `variante_color_id`. Si no se localiza la fila, la operación se interrumpe lanzando un **404 Not Found**, evitando la inyección de huérfanos multimedia.
* **CA-03 (Validación de Formato de URL Estática):** El campo `url` es obligatorio y debe cumplir con una estructura de ruta válida. Puede aceptar tanto rutas relativas del ecosistema local (ej. `/images/products/nike_1.png`) como URLs absolutas de un servicio de almacenamiento en la nube, validadas estrictamente por Pydantic antes de tocar el ORM.
* **CA-04 (Carga Inversa y Limpieza de Hilos):** El borrado de una imagen remueve el registro físico de MySQL de manera atómica. El controlador debe asegurar la ejecución de un bloque `try-except` con `db.rollback()` para evitar inconsistencias relacionales si ocurre un corte de red inesperado durante el borrado.

---

#### 📊 3. Esquemas de Validación y Contratos de Datos (Pydantic)

```python
from pydantic import BaseModel, Field
from typing import Optional

# Esquema de Entrada para registrar recursos multimedia
class ImagenCreate(BaseModel):
    url: str = Field(
        ..., 
        min_length=5, 
        examples=["/images/products/airforce_root_1.png"],
        description="Ruta de almacenamiento local o URL absoluta del recurso estático"
    )
    variante_color_id: int = Field(..., description="ID de la variante de color a la que se ancla")

# Esquema de Respuesta de la Entidad Imagen
class ImagenResponse(BaseModel):
    id: int
    url: str
    variante_color_id: int

    class Config:
        from_attributes = True
```

#### 🛣️ 4. Matriz de Endpoints y Contratos JSON

| Método | Endpoint | Acceso | Descripción | Códigos HTTP Esperados |
| :--- | :--- | :--- | :--- | :--- |
| **POST** | `/api/productos/imagenes` | **Admin** | Vincular una imagen a una variante | `201 Created`, `404`, `401`, `403` |
| **DELETE** | `/api/productos/imagenes/{id}` | **Admin** | Remover una imagen del catálogo físico | `200 OK`, `404`, `401`, `403` |

##### 📥 Ejemplo de Payload de Entrada (POST `/api/productos/imagenes`):
```json
{
  "url": "/images/products/af1_black_lateral.png",
  "variante_color_id": 1
}
```

##### 📤 Ejemplo de Respuesta Exitosa (HTTP 201 Created):
```json
{
  "id": 12,
  "url": "/images/products/af1_black_lateral.png",
  "variante_color_id": 1
}
```

#### 🗄️ 5. Implementación del Algoritmo del Controlador (FastAPI + SQLAlchemy)

```python
from fastapi import APIRouter, Depends, HTTPException, status
from sqlalchemy.orm import Session
from app.database import get_db
from app.models.variant import VarianteColor, Imagen
from app.schemas.variant import ImagenCreate, ImagenResponse
from app.routers.auth import verificar_admin

router = APIRouter(prefix="/api/productos", tags=["Productos"])

@router.post(
    "/imagenes", 
    status_code=status.HTTP_201_CREATED, 
    response_model=ImagenResponse,
    summary="Vincular un nuevo recurso de imagen a una variante física (Solo Admin)"
)
def agregar_imagen_galeria(
    payload: ImagenCreate, 
    db: Session = Depends(get_db),
    admin_actual = Depends(verificar_admin)
):
    # 1. Validar existencia previa de la variante de color base en MySQL
    variante = db.query(VarianteColor).filter(VarianteColor.id == payload.variante_color_id).first()
    if not variante:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail=f"Inconsistencia Multimedia: La variante de color con ID #{payload.variante_color_id} no existe."
        )

    try:
        # 2. Instanciar el modelo declarativo ORM
        nueva_imagen = Imagen(
            url=payload.url.strip(),
            variante_color_id=payload.variante_color_id
        )
        
        # 3. Consolidar inserción atómica en base de datos
        db.add(nueva_imagen)
        db.commit()
        db.refresh(nueva_imagen)
        return nueva_imagen
        
    except Exception as e:
        db.rollback()
        raise HTTPException(
            status_code=status.HTTP_500_INTERNAL_SERVER_ERROR,
            detail=f"Fallo del motor al asociar el recurso multimedia: {str(e)}"
        )

@router.delete(
    "/imagenes/{id}", 
    status_code=status.HTTP_200_OK,
    summary="Remover físicamente una imagen de la base de datos (Solo Admin)"
)
def eliminar_imagen_galeria(
    id: int, 
    db: Session = Depends(get_db),
    admin_actual = Depends(verificar_admin)
):
    # 1. Buscar la entidad multimedia en MySQL
    imagen = db.query(Imagen).filter(Imagen.id == id).first()
    if not imagen:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail=f"Error de Eliminación: El registro multimedia con ID #{id} no existe."
        )
        
    try:
        # 2. Ejecutar HARD DELETE transaccional
        db.delete(imagen)
        db.commit()
        return {"detail": f"Operación Exitosa: El recurso #{id} fue removido del catálogo relacional."}
        
    except Exception as e:
        db.rollback()
        raise HTTPException(
            status_code=status.HTTP_500_INTERNAL_SERVER_ERROR,
            detail=f"Fallo del motor relacional durante la remoción física: {str(e)}"
        )
```

### 📋 HU-03: Despliegue de Vitrina Comercial Paginada

**Como** Cliente de la plataforma SneakerHub  
**Quiero** visualizar el catálogo de zapatillas activas de forma paginada mediante parámetros de control de flujo (página y límite)  
**Para** navegar por la tienda de manera fluida y optimizada, reduciendo el consumo de datos y agilizando el renderizado visual en el cliente web.

---

#### 📌 1. Precondiciones y Postcondiciones
* **Precondiciones:**
  1. La base de datos MySQL debe contener registros en la tabla `productos` asociados a sus marcas y categorías correspondientes.
  2. Los índices relacionales de las claves foráneas deben estar optimizados para evitar retrasos en las lecturas secuenciales.
* **Postcondiciones:**
  1. El servidor procesa la segmentación física de los datos mediante cláusulas de desplazamiento.
  2. El cliente frontend (React) recibe un objeto JSON estructurado que encapsula tanto el arreglo de ítems del catálogo como los metadatos de control para construir los componentes interactivos de paginación.

---

#### 🛠️ 2. Criterios de Aceptación Técnicos Detallados
* **CA-01 (Libre Acceso Perimetral):** Este endpoint representa la ventana de exposición pública del e-commerce. Por lo tanto, no debe requerir cabeceras de autorización (`Authorization`) ni validaciones JWT. El acceso es totalmente anónimo y sin restricciones de sesión.
* **CA-02 (Filtro de Estado Comercial Obligatorio):** Por motivos de consistencia de cara al consumidor, el algoritmo de extracción debe inyectar de forma mandatoria una cláusula de filtrado estricto donde la columna `estado` sea idéntica al literal **"ACTIVO"**. Cualquier calzado marcado como "INACTIVO" (Soft Delete o descontinuado) debe omitirse del set de datos devuelto.
* **CA-03 (Parámetros de Control y Valores por Defecto):** El endpoint interceptará las consultas mediante Query Parameters:
  * `page`: Controla el bloque actual. Valor entero mínimo: 1. Por defecto: **1**.
  * `limit`: Cantidad de registros por bloque. Valor entero mínimo: 1, Máximo permitido: 50 (para mitigar ataques de denegación de servicio por extracción masiva). Por defecto: **12**.
* **CA-04 (Cálculo Automático de Desplazamiento Matemático):** La segmentación en MySQL se calculará dinámicamente en el backend aplicando la ecuación:

  `offset = (page - 1) * limit`

* **CA-05 (Sobre-encapsulamiento de Metadatos / Envelope JSON):** La respuesta no debe ser un arreglo plano. Debe envolverse en una estructura que provea telemetría de control: cantidad total de registros coincidentes en la base de datos (`total_items`), número de la página actual (`current_page`), límite por página (`page_size`) y el total de páginas calculado (`total_pages = ceil(total_items / limit)`).

#### 📊 3. Esquemas de Validación y Contratos de Datos (Pydantic)

```python
from pydantic import BaseModel, Field
from typing import List, Optional

# Esquema para envolver los metadatos de paginación
class PaginaMetadatos(BaseModel):
    total_items: int = Field(..., description="Cantidad total de registros activos coincidentes en MySQL")
    total_pages: int = Field(..., description="Cantidad total de páginas disponibles")
    current_page: int = Field(..., description="Índice de la página actual consultada")
    page_size: int = Field(..., description="Límite de calzados renderizados por página")

# Esquema simplificado del calzado para el listado de vitrina
class ProductoVitrinaResponse(BaseModel):
    id: int
    nombre: str
    precio_base: float
    porcentaje_descuento: float
    descripcion: Optional[str]
    marca_nombre: str
    categoria_nombre: str
    estado: str

    class Config:
        from_attributes = True

# Contrato Final de Salida (Envelope)
class VitrinaPaginadaResponse(BaseModel):
    items: List[ProductoVitrinaResponse] = Field(..., description="Listado segmentado de productos")
    paginacion: PaginaMetadatos = Field(..., description="Metadatos de control para el frontend")
```

#### 🗄️ 5. Implementación del Algoritmo del Controlador (FastAPI + SQLAlchemy)

```python
from fastapi import APIRouter, Depends, Query, status
from sqlalchemy.orm import Session
from math import ceil
from app.database import get_db
from app.models.product import Producto
from app.schemas.product import VitrinaPaginadaResponse, ProductoVitrinaResponse, PaginaMetadatos

router = APIRouter(prefix="/api/productos", tags=["Productos"])

@router.get(
    "/vitrina", 
    response_model=VitrinaPaginadaResponse,
    status_code=status.HTTP_200_OK,
    summary="Listar catálogo de productos activos de forma paginada (Acceso Público)"
)
def obtener_vitrina_paginada(
    page: int = Query(default=1, ge=1, description="Número de la página a consultar"),
    limit: int = Query(default=12, ge=1, le=50, description="Cantidad de registros por página"),
    db: Session = Depends(get_db)
):
    # 1. Construir base de la consulta filtrando estrictamente productos ACTIVOS
    base_query = db.query(Producto).filter(Producto.estado == "ACTIVO")
    
    # 2. Ejecutar conteo atómico total en MySQL antes de segmentar (Indispensable para metadatos)
    total_items = base_query.count()
    
    # 3. Calcular offset matemático para la segmentación física de filas
    offset_calculado = (page - 1) * limit
    
    # 4. Extraer los productos aplicando paginación a nivel de base de datos (LIMIT y OFFSET)
    productos_paginados = base_query.order_by(Producto.id.desc()).offset(offset_calculado).limit(limit).all()
    
    # 5. Mapear y formatear la salida estructurando los subtitulos relacionales de texto
    items_formateados = []
    for prod in productos_paginados:
        items_formateados.append(
            ProductoVitrinaResponse(
                id=prod.id,
                nombre=prod.nombre,
                precio_base=prod.precio_base,
                porcentaje_descuento=prod.porcentaje_descuento,
                descripcion=prod.descripcion,
                marca_nombre=prod.marca.nombre if prod.marca else "Sin Marca",
                categoria_nombre=prod.categoria.nombre if prod.categoria else "Sin Categoría",
                estado=prod.estado
            )
        )
    
    # 6. Calcular total de páginas redondeando hacia el entero superior
    total_paginas = ceil(total_items / limit) if total_items > 0 else 1
    
    # 7. Retornar el sobre-encapsulamiento final (Envelope JSON)
    return VitrinaPaginadaResponse(
        items=items_formateados,
        paginacion=PaginaMetadatos(
            total_items=total_items,
            total_pages=total_paginas,
            current_page=page,
            page_size=limit
        )
    )
```

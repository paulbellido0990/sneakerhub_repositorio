### 📋 HU-04: Motor de Búsqueda Avanzada y Filtros Cruzados

**Como** Cliente de la plataforma SneakerHub Ayacucho  
**Quiero** buscar modelos de calzado filtrando de manera combinada por términos de texto parcial (marca, nombre) o disponibilidad de tallas específicas  
**Para** localizar rápidamente las zapatillas de mi interés que tengan existencias reales en almacén, mejorando la experiencia de compra y evitando frustraciones por quiebres de stock.

---

#### 📌 1. Precondiciones y Postcondiciones
* **Precondiciones:**
  1. El motor de base de datos MySQL debe tener debidamente indexadas las columnas de búsqueda (`nombre` en productos, `nombre` en marcas, y `talla` en la matriz de inventario) para garantizar tiempos de respuesta inferiores a 200ms.
  2. El catálogo debe contar con la hidratación de stock correspondiente (ej. mediante el script `seed_tallas.py`).
* **Postcondiciones:**
  1. El sistema retorna un arreglo estructurado con todos los productos que cumplan simultáneamente con los filtros cruzados activos.
  2. Los resultados exponen la estructura profunda del calzado (variantes, imágenes y tallas con stock) reduciendo las solicitudes asíncronas subsecuentes desde el frontend.

---

#### 🛠️ 2. Criterios de Aceptación Técnicos Detallados
* **CA-01 (Navegación Pública Desacoplada):** Al ser un endpoint crítico para la indexación y la experiencia del usuario, la ruta de búsqueda avanzada no exige cabeceras de autorización Bearer Tokens ni interceptores de sesión. Es de acceso 100% público.
* **CA-02 (Filtro por Coincidencia Parcial de Texto):** El parámetro opcional `q` (Query) debe evaluar coincidencias parciales sobre la columna `nombre` del producto utilizando la cláusula SQL `LIKE %q%` combinada con funciones de insensibilidad a mayúsculas/minúsculas (`.ilike()`).
* **CA-03 (Filtro Elástico de Tallas y Exclusión de Quiebres de Stock):** Si el cliente envía el parámetro opcional `talla`, el backend debe realizar un `JOIN` relacional explícito hacia la subtabla de inventarios (`TallaStock`). La consulta debe aislar y retornar únicamente los productos que cuenten con existencias físicas reales para dicha talla en almacén, aplicando la condición matemática:

  `TallaStock.talla == talla`  Y  `TallaStock.stock > 0`

* **CA-04 (Inyección Masiva contra el problema N+1):** El algoritmo del controlador debe forzar una carga profunda elástica (*Eager Loading*) mediante `joinedload` encadenados. Debe traer en un solo viaje SQL la marca, la categoría, las variantes de color adjuntas, las galerías de imágenes y la matriz completa de existencias, garantizando una complejidad de tiempo $O(1)$ en consultas a la base de datos.

```python
from pydantic import BaseModel, Field
from typing import List, Optional

# Esquemas de soporte para las relaciones anidadas profundamente
class TallaStockSchema(BaseModel):
    id: int
    talla: str
    stock: int

    class Config:
        from_attributes = True

class ImagenSchema(BaseModel):
    id: int
    url: str

    class Config:
        from_attributes = True

class VarianteColorSchema(BaseModel):
    id: int
    color: str
    imagenes: List[ImagenSchema] = []
    tallares_stock: List[TallaStockSchema] = []

    class Config:
        from_attributes = True

# Contrato Final de Salida para el Motor de Búsqueda
class ProductoBusquedaResponse(BaseModel):
    id: int
    nombre: str
    precio_base: float
    porcentaje_descuento: float
    descripcion: Optional[str]
    estado: str
    marca_nombre: Optional[str] = None
    categoria_nombre: Optional[str] = None
    variantes_color: List[VarianteColorSchema] = []

    class Config:
        from_attributes = True
```

#### 🗄️ 5. Implementación del Algoritmo del Controlador (FastAPI + SQLAlchemy)

```python
from fastapi import APIRouter, Depends, Query, status
from sqlalchemy.orm import Session, joinedload
from typing import List, Optional
from app.database import get_db
from app.models.product import Producto
from app.models.variant import TallaStock, VarianteColor
from app.schemas.product import ProductoBusquedaResponse

router = APIRouter(prefix="/api/productos", tags=["Productos"])

@router.get(
    "/buscar", 
    response_model=List[ProductoBusquedaResponse],
    status_code=status.HTTP_200_OK,
    summary="Motor de búsqueda avanzada con filtros cruzados de texto y tallas"
)
def buscar_productos_avanzado(
    q: Optional[str] = Query(default=None, description="Término de búsqueda parcial (Nombre/Marca)"),
    talla: Optional[str] = Query(default=None, description="Filtrar calzados con stock real en esta talla"),
    db: Session = Depends(get_db)
):
    # 1. Inicializar la consulta base aplicando optimización de Carga Profunda Eager (Mitigación N+1)
    query = db.query(Producto).options(
        joinedload(Producto.marca),
        joinedload(Producto.categoria),
        joinedload(Producto.variantes_color).joinedload(VarianteColor.tallares_stock),
        joinedload(Producto.variantes_color).joinedload(VarianteColor.imagenes)
    ).filter(Producto.estado == "ACTIVO")
    
    # 2. Aplicar filtro elástico de coincidencia parcial de texto si se provee 'q'
    if q:
        query = query.filter(Producto.nombre.ilike(f"%{q.strip()}%"))
        
    # 3. Aplicar filtro cruzado de inventario si se solicita una 'talla' específica
    if talla:
        query = query.join(Producto.variantes_color)\
                     .join(VarianteColor.tallares_stock)\
                     .filter(TallaStock.talla == talla.strip())\
                     .filter(TallaStock.stock > 0)
                     
    # 4. Ejecutar consulta consolidada en MySQL (Garantía O(1) viajes de red)
    resultados = query.order_by(Producto.id.desc()).all()
    
    # 5. Formatear la respuesta mapeando las propiedades relacionales del ORM
    respuesta_mapeada = []
    for prod in resultados:
        respuesta_mapeada.append(
            ProductoBusquedaResponse(
                id=prod.id,
                nombre=prod.nombre,
                precio_base=prod.precio_base,
                porcentaje_descuento=prod.porcentaje_descuento,
                descripcion=prod.descripcion,
                estado=prod.estado,
                marca_nombre=prod.marca.nombre if prod.marca else "Genérico",
                categoria_nombre=prod.categoria.nombre if prod.categoria else "General",
                variantes_color=prod.variantes_color
            )
        )
        
    return respuesta_mapeada
```
